# Dashboard de Cartoes - Sicoobcard (coop 4340)

Pagina HTML de arquivo unico com o BI de cartoes: resultado por PA e por produto, linhas de receita e despesa, Lounge Key, simulador de anuidade e contas em atraso por faixa.

- `index.html` - abrir direto no navegador (funciona offline, Chart.js embutido)
- `BI_Cartoes_Sicoobcard.html` - mesma pagina, nome do arquivo de trabalho

Base: `4340 - Rentabilidade Sicoobcard.xlsx` (abas Base DRE, Faturamento, Cessao e Cartoes em Atraso).
Atualizacao mensal: regerar a pagina a partir da planilha e substituir os dois arquivos.
